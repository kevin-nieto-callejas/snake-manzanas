# Snake Manzanas 🍎🐍

Juego sencillo basado en el Snake clásico.

## Cómo jugar

La serpiente se controla con las flechas del teclado:

* ↑ Arriba
* ↓ Abajo
* ← Izquierda
* → Derecha

## Reglas

* 🍎 Al comer una manzana normal, la serpiente crece 1 segmento.
* 🪱 Algunas manzanas tienen un gusano pequeño y difícil de ver.
* Si la serpiente come una manzana con gusano, su longitud se reduce a la mitad.
* Si la serpiente choca contra una pared o contra su propio cuerpo, pierde.
* Se puede volver a jugar usando el botón de reinicio.
